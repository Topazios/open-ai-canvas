# 功能清单

## 画布全局创作设定（待人工验收）

新建短剧画布通过枚举选择题材、视觉形式、画风、叙事、语言、地域、年代、画幅与单集时长，并填写总集数。语言和地域位于主要设置，其他可选约束折叠展示；已有故事和剧本可导入文本。画布顶部和专注模式提供编辑入口。后续短剧任务继承设定版本，已生成内容与运行中任务不自动重写；资产参考板保留统一横向布局。画布列表“更多”菜单支持自由画布、导入、创作历史、刷新及带确认的批量删除。

## 资产制作 Agent（待人工验收）

新建项目制作方案前置故事、视觉、导演视听、生成一致性四份规范与五类资产档案，资产由服务端分配稳定编码。正文完成后通过一次“正文资产校核与补充”长任务跨集归并实际应用；参考图也可直接使用前置资产。工作流提示词支持 `@资产编码` 选择并解析当前来源版本。任务面板支持暂停、继续、取消及重新打开后恢复；已编辑/删除的节点受到保护。分镜使用单集正文与持久场次检查点，真实模型语义完整性、成本及耗时待验收。

## 短剧流程与本地审片记录

历史五类资产任务继续使用原有分类合同及共享正文事实。新项目使用前置方案和统一资产校核，避免重复设计规范或逐类别重复拆解。正文事实绑定原文与模型版本，制作约束与正文证据分开；来源变化和人工修订仍须校验，不跨版本复用内容。详情、参考图与后续提示词保留资产编码，旧资产不自动改号。

普通节点和阶段容器连线自动选择四边上的最短接点，保留源到目标的数据方向；显式分镜行与批量引用端口保持固定语义。拖动连接可吸附普通节点边框任意邻近位置，最终按最短距离定位。连线增加沿来源到下游的轻量流转动画，拖动节点同步，视口操作、后台标签页和减少动态效果模式暂停。此路由不绕开第三方障碍节点；重叠节点仍应先调整布局。

阶段容器展开或折叠时都作为一个连线端点：同一来源与容器、两个容器间只显示一条关联线。底层保留每份文稿的具体来源和指纹；删除可见关联线会解除整组对应连线，避免删后又出现另一条。分享页和版本预览使用同一规则，旧画布打开即可生效，不重新生成正文。

资产阶段提供五个常驻入口：统一制作规范、人物资产、场景资产、道具资产、特殊资产。特殊资产无需勾选，有需要直接生成，无需时可跳过，不是下游的必需来源。当前八阶段共 33 个步骤，保留旧文稿和已提交任务。先从正文容器生成完整的统一制作规范，即可直接提取其它资产，不再要求先手动确认；提取表、总表或单独声音提示词不作为新流程步骤。

统一制作规范由一个原生容器承载提取记录、故事设定、表现风格。后两项可分别用原文本编辑器修改；右键“查看并确认制作规范”仍可选用，修改后原确认状态失效，但不阻断基于当前完整规范的新资产生成。未完成、缺失、前文过期或关联断开的规范仍不能作为来源，不自动伪造确认。人物资产包含服装妆发、状态变化与固定声线；场景资产包含空间、日夜天气与环境声；关键道具包含归属、交接损坏状态和标志音；特殊资产承载可复用特效、界面和符号。实际配音与音乐音效制作仍在声音阶段。

每项资产是普通文本节点，容器右键继续下游。单项右键“资产资料与参考”可维护别名、逐集场次、状态、所属人物、空间、正文证据、变体、声音、冲突以及画布图片/音频/视频参考。状态区分仅描述、候选参考、已选定参考版本和失效参考；生成提示词不等于已制作媒体。按集生成时只注入相关资产和当前选定参考；索引为空或正文编辑后未核对时保守保留并标记待核对。来源、规范和参考变动会使既有下游版本过期。

分组结果通过原任务消费链路保存并恢复，重复任务回填不再次拆分，也不覆盖已编辑或已删除的成员。格式错误保留原始结果并标记失败，不生成半个分组；可以生成另一版。超过单次上下文预算的材料自动按集/来源分批，单集过长再按段落拆分；后端逐批提取、跨集归并，必要时多层汇总，原文不静默截断。关闭页面后任务继续，重开显示批次进度；任务中心重试总任务会复用成功批次，费用待核对的失败批次不会自动重发。每次实际模型调用独立入队与计费，总任务只协调、不重复收费。实际提取完整性、别名归并与提示词质量待人工核验，生成文稿不代表参考图或音频已制作。

流程导引改为窄幅可移动浮窗，默认展开当前阶段，用下拉框切换八阶段；完整总览按需打开，任务区内部滚动。顶部拖动手柄移动浮窗，位置按账号在本机保存；窗口或侧栏尺寸变化时限制在可用区域，可继续折叠或隐藏。

制作方案的结构化计划集数与单集时长沿所选版本向下继承；正文生成面板展示总集数、时长、完成/进行中/失败/待提交/未生成数量，导引同步显示正文进度。计数按当前集纲分支和集号去重，不把另一份方案的正文拼成已完成。

分集正文自动进入现有背板容器，保留逐集普通文本节点、任务和来源。不同集的补生成可追加同源容器；重复集生成保留旧容器并创建另一容器版本。旧的未分组正文可右键“整理同源分集为容器”，无需重新调用模型。容器可以移动、折叠，显示分集进度；下一步可以选择整组，也可选择单集。

已有文稿支持多选后右键节点或空白处，使用“将所选节点归入阶段容器”，只整理所选内容；菜单同时列出兼容的“加入容器”目标。普通背板内已有同流程、同一步骤分集文稿时，可右键“识别为阶段容器”，保留原背板 ID 与名称，随后右键进入对应下一步。阶段容器右键不再被多选菜单屏蔽；混用流程、步骤、同集多版本或不同前置分支会明确阻断归组。

后续只发送直接依赖文稿与制作方案，不反复嵌入所有历史正文；资产生成读取所选正文，后续分镜读取相应分组与本集材料，覆盖范围限于所提供集数，不冒充整季齐备。长材料自动分批并保留来源、集号和冲突，只有最终文稿回填画布。未完成成员、不同集数范围、冲突版本或过期来源需处理后才能整组继续。旧提取与总表文稿及活动任务保留原依赖合同，不自动改写。

除选题外，八阶段中的其余 33 个步骤统一使用精简生成面板，仅提供模型、必要的来源版本、制作参数和补充要求；不再包含正文、预览、撤销或采用区域。每次生成创建新的普通文本节点或资产分组，保留原节点与已有分支。结果直接显示在画布上，右键“放大编辑”使用现有文本编辑器。新建短剧流程只创建选题，后续文稿按生成操作创建。

制作方案可设置计划集数、单集时长；分集正文保留起始集数和本次生成集数，例如起始 2、数量 3 创建第 2–4 集三个独立节点和任务。再次生成同一范围会创建新的版本，不覆盖或跳过已有正文。各集任务可在现有任务中心查看和停止。

阶段和步骤使用统一枚举与依赖表；节点保存阶段、步骤、流程 ID、集数、版本、具体来源节点及来源指纹。右键按步骤显示“下一步”和“生成另一版”，下一步带入所选分支并自动连接所有直接前置节点。多个前置版本不自动猜选，缺失、已删除、跨流程、跨集、版本冲突、循环依赖或断开的来源连线阻止提交。新版本不会自动把已有下游改接过去。

生成前先将结果节点与提交标记保存到云端，然后使用现有后台文本任务和结果消费链路。关闭面板不会取消已提交任务，刷新画布后按节点及任务 ID 恢复；未提交节点可右键继续提交，回执不确定时查询原任务，不自动重发。旧编辑器本机草稿和后台任务继续在原用户作用域恢复，冲突时保留草稿并提示，不覆盖更新后的画布内容。

剧情与章节保持“选题 → 制作方案（含故事总纲）→ 分集集纲 → 分集正文”。资产、分镜、声音、视频、剪辑、质检和交付步骤生成对应制作文稿或执行清单；这些文本不表示媒体已经生成、实际渲染或审核已通过。实际媒体操作继续使用现有分镜、生成、剪辑及交付工具，阶段完成状态不因一份清单而虚报通过。历史粗纲和原画布内容保留。

选题编辑器右侧填写类型、风格、核心设定及生成数量，左侧展示候选选题和采用后的草稿；每次可生成 1–10 个选题，默认 4 个。类型之外的制作体量信息不再要求在选题表单提前填写，历史参数仍保留用于后续制作步骤。模型返回数量不符时明确报错并保留原候选。

自由画布可从画布菜单或专注模式工具栏显式选择项目和章节，保存后核对原节点列表、目标章节与映射边界，再确认关联；成功后可打开该章节八阶段工作台。服务端将画布归属、章节关系与历史一起保存，旧预览不能覆盖新画布。关联不会自动把节点变成项目镜头、替换章节正文或补造审核记录。

同一弹窗可逐项关联画布节点与当前章节正式镜头，选择可选的已采用产物版本，并在预览后确认。重新打开可读取关系，镜头修订、删除或产物换版后显示需复核；解除关系保留原节点和项目镜头。当前仅建立身份及版本关系，共享业务内容展示、资源后来失效的状态回显及审核/交付记录同步仍待完成。

剪辑保存冲突或写入失败时，会尝试保留本机草稿。重新进入可对照当前剪辑与草稿，继续当前版本或明确恢复；恢复前保留旧版本备份，后续可再次打开。不同编辑器会话互不覆盖草稿，过期恢复预览会被拒绝；若草稿存储也失败，会明确提示刷新可能丢失当前修改。该功能不包含自动合并、服务端归档或尚未提交快照的恢复保证。

按集剪辑在没有本集记录而存在旧项目剪辑时，会显示归属预览，列出片段和时长；用户选择目标集并确认后才沿用旧剪辑，也可从空白开始。原项目级记录保留，同一旧剪辑不能重复分配到其他集，已有本集内容不会被覆盖。保存会检查上次读取的版本，另一页面已更新时明确报冲突并保留当前编辑内容；该归属和保存仍在本机用户作用域内。

自由画布导引和项目工作台共用八阶段名称；画布默认只展开当前阶段，用户可以进入全部阶段总览，目前画布共 33 项子任务。剧情与章节阶段提供独立的选题抽取、制作方案、分集集纲和分集正文节点。选题根据类型、风格和核心设定生成候选，用户采用后才进入制作方案；后续步骤读取已保存的上游节点，并通过上游变更提示保持人物、规则和因果连续。每个节点可以单击编辑或双击打开创作编辑器，完整 AI 正文直接写入编辑区并支持上一版撤销，正文按集独立创建。其余资产、分镜、配音、视频、剪辑、质检和交付任务继续复用现有入口，尚未接入的审核、归档和正式交付记录保持明确的待接入状态。

当前集剪辑器的“当前集镜头”面板列出采用视频、真实时长、缺失或过期原因，并可将可用镜头按顺序追加到时间线末尾。采用视频变化时可打开替换对照，检查原/新素材及拆分片段的源区间，再整组换源，保留裁剪、时间位置、名称、音量和淡入淡出；过短素材与旧对照方案拒绝提交。整组操作支持一步撤销/重做和本机保存恢复。已删除来源的片段保留并提供定位；默认轨道保存过的锁定、静音和可见性在刷新后保留。

资产拆分阶段拆为项目画风、剧本候选、角色版本、场景/道具版本和资产一致性确认五项，复用项目设置、章节候选和资产库数据提供对应入口；没有独立审核记录时保持待复核。配音与声音阶段拆为台词/旁白、角色声线与试听、声音素材、音画对齐四项，复用当前镜头修订、角色资产、采用音频和剪辑器数据展示真实数量并提供对应入口。采用音频可按明确的对白或镜头内时间区间追加到当前镜头对应音轨；缺少区间、媒体真实时长、当前镜头视频锚点或跨剪辑断点时会阻断，已入轨的相同产物保持幂等，区间变化会保留提示并要求复核。历史无绑定片段的镜头映射、来源变化对正式审核的完整影响仍待后续接入。加载失败或损坏的时间线提供重试，避免空白编辑覆盖旧记录；真实播放与导出对照仍须人工验收。

审片记录还会保存当前集镜头来源依赖指纹。镜头改选视频、修改修订、删除来源或尚未进入时间线时，即使时间线位置没有变化，质检页也会显示具体阻断原因并禁止确认；确认动作会重新读取当前集和时间线。旧记录缺少该指纹时需重新渲染审片。

成片质检支持标记播放时间并选择当时的片段，问题保存后可以点击时间点返回画面。批注绑定原审片资源和源素材偏移；重新渲染后，来源明确且位置唯一的片段可重新定位，删除、换源或歧义会提示人工重新定位。问题编辑期间审片文件变化不会自动将旧时间点写到新文件，草稿保留；关联的项目镜头可返回既有制作工作台。该记录仍保存在本机，真实渲染后的帧位置需要人工核验。

项目审片记录按当前用户、项目和集数保存在本机。服务端渲染结果绑定提交时的时间线快照；已保存时间线变化或记录读取失败时，旧成片不再显示当前版本已核验。修改审片问题和确认时检查记录版本，冲突不会覆盖新记录。导出成功但记录保存失败时，可单独重试保存记录。服务端审片归档、实际文件播放和跨标签浏览器验收仍待完成，详见[待测试](/docs/progress/pending-test)。

## 画布媒体产出模型

图片、视频、音频在生成成功并写入节点后，会冻结当时提交的产出模型。提示词面板里的模型下拉仍是下一次要用的选用模型，改下拉不会改掉已经生成的内容。画布外观中的「媒体信息」打开后，有内容的媒体节点在左下角显示产出模型；图片右下角继续显示尺寸和体积。上传、粘贴、截取、合并、提取音频和本地加工不记录产出模型。本次改动之前的节点不回填。分享页和版本预览画布不显示这块信息。

## 画布 Agent 名称、文案与形象

「站点及外观 → 画布配置」提供独立助手名称、入口文字、面板标题和欢迎/输入文案。支持导入授权的 Live2D Cubism 3/4 运行时 ZIP，预览后保存启用、调整高度、切回默认动态球。加载失败保留可点击的默认入口，上传和资源访问具有管理员校验和引用保护。Cubism Core 由部署者提供，真实播放待验收；不含图片自动建模或 AI 自我介绍同步。详见 [画布 Agent 外观与 Live2D](/docs/backend/canvas-agent-appearance)。

## 素材库分类与画布媒体链路

素材库支持用户手动新增、重命名和删除分类，也可以按分类或“未分类”筛选素材，并批量移动素材。删除分类不会删除素材，分类内素材会回到“未分类”。

画布中的远程图片、视频和音频展示统一使用资源文件地址，不把浏览器 Blob Object URL 写入节点或预览状态；Blob 缓存只用于导出、抽帧、供应商输入等字节处理。画布生成的视频在进入成功态前会先完成资源 Blob 缓存，缓存失败会保留失败语义，不会显示为已成功。

### 相关实现

- `web/src/pages/assets/index.tsx`：素材库分类筛选、新建、重命名、删除和批量移动入口。
- `web/src/services/api/user-data.ts`：素材分类及素材移动 API。
- `web/src/services/file-storage.ts`、`web/src/services/image-storage.ts`：远程资源地址解析。
- `web/src/services/resource-blob-cache.ts`：按用户 scope 隔离的媒体字节缓存。

## 画布连线可读性与底部工作条

## 云端 Agent（写入与生成仍待真实环境验收）

浮窗支持移动、调整大小和浏览器偏好恢复；后端支持逐轮对话、可信历史、取消、Skills 快照、画布摘要/精读、审批后的画布写入及媒体生成。运行中可插话（下一步生效，不打断正在飞的调用）；多步任务可用 `plan_update` 维护待办清单并在输入框上方展示，未完成项会催办；`request_approval` 下首次 ≥2 项清单会先确认，`auto` 直接建立。`ask_user` 可弹出选项并结束本轮。个人记忆由 `remember_lesson` 写入待审，用户在「设置 → Agent 记忆」自己批准、添加、导出导入，并可用自己的文本模型手动或按日/周/月压缩相近条目。系统提示只带已批准记忆的索引（标题+适用场景），完整做法由 `recall_lessons` 按 topic/关键词取；管理员可按用户查看和删除，不能代批。只读模式不能写记忆。终态旧轮次按其冻结合同保留为不可变历史，新消息使用当前合同创建新轮，不篡改父运行；旧合同下仍活动或待审批的运行不会被新版服务恢复执行。生成由预算和独立审批控制，画布写入使用内容快照哈希；未开放外部 MCP。系统行为策略以版本化资源发布，用户/项目/画布可编辑常驻偏好；偏好正文固定在运行快照并按层只读，不整段塞入 system prompt，也不能提权或跳过审批。节点创建、更新字段、摘要投影和连线限制来自服务端能力 registry；能力卡同时描述用途、适用场景、不适用场景、维护代价和可用动作，由 Agent 结合镜头数量、连续性、逐镜审查和交接需求自主选择，不强制所有任务使用分镜。分镜脚本支持结构化创建、分页读取及按真实行 ID 追加、修改和删除；普通文本和 Markdown 不会被宣称为具备镜头级维护能力的分镜表。图片、视频和音频节点可安全修改标题与下一版提示词草稿，既有媒体、已提交提示词和任务状态不会被草稿编辑覆盖；媒体模型按生成模式和真实参考节点从统一目录筛选。审批和执行记录明确展示目标节点、类型、修改字段、名称变化及连线两端，前端不再依靠内部 ID 猜测；这些预览不替代服务端归属、快照、Capability、锁、预算与调用哈希校验。真实模型计费与浏览器联调仍待验收。

云端画布 Agent 已分离行为策略、用户目标、参考事实和运行状态。续聊保留已送达插话，不再继承代码预设的创作自由；旧待办只作上下文，可移除取消项，催办不会强制工具调用或无限重复。提示词来源与发布约束见[画布 Agent 提示词与用户意图](/docs/backend/agent-prompt-policy)，真实模型行为仍待场景验收。

## 画布保存保护与版本记录

旧页面或旧缓存不能覆盖云端新内容。每次内容保存核对服务端版本，发生冲突会停止该画布自动提交并保留本地草稿；平移、缩放和打开画布不触发整份内容保存。画布顶部显示保存状态，可保留草稿后加载云端最新版。

此功能不提供多人实时协同或自动合并两个浏览器的完整画布；版本保护用于阻止静默覆盖。历史从升级后开始积累。

## 系统渠道排序与前台别名

系统渠道模型选择器直接读取渠道下的模型列表：一级跨渠道按“模型展示名”分组并显示原色 Logo，二级显示该模型的“渠道展示名”及规格售价；留空使用所属渠道名称。模型调用标识不必相同，也不反查逻辑模型。系统渠道的“前台名称”已移除。调用保留用户选中的具体渠道，收起后显示“模型 · 渠道”，不因另一渠道更便宜而自动切换。图标优先使用图标库的原色版本，缺少彩色版本时使用单色版本；缺少配置时显示通用图标，不猜测产品品牌。

共用模型面板宽度上限 560px，左右产品/渠道列表分别滚动，渠道标题保持可见；切换产品时渠道回到顶部。选定后关闭并回到触发器焦点，方向键/Home/End 在当前列表内导航；窄窗使用单栏与返回按钮。布局统一维护在公共样式，不再由工作区页面重复覆盖。

渠道模型价格档支持管理员单独配置积分成本价；后台请求记录同时显示销售金额和成本金额。成本按下单快照计算，不追随之后改价；普通用户页面及接口不返回成本字段。

系统渠道模型列表按规格显示成本价 / 销售价及利润率；文本输入、输出、缓存 Token 分开呈现。勾选多个模型可统一调价：弹窗一行一个模型，展示模型名、渠道展示名（上游 ID）、规格、成本与可编辑售价，多规格在模型行内纵向对齐。输入目标利润率并选择保留 0–6 位小数（默认 2 位），按 `成本 / (1 − 利润率)` 四舍五入实时计算；也可点击「重新计算」覆盖手动值，再逐项修改。保存最终输入售价，服务端校验价格与版本并原子保存，不改变成本或启停状态。

后台系统渠道通过“设置排序”、模型管理通过“自定义排序”打开完整列表。支持搜索选择条目后输入目标位置，也可拖动、上移和下移；列表显示从 1 开始的位置，点击“保存排序”统一生效，取消不会修改线上顺序。渠道行的“更多”菜单支持复制渠道，复制会生成独立的渠道、模型和价格档，并保留原连接配置与凭证。排序不受筛选及分页影响；并发修改会提示重新加载，避免覆盖其他管理员的调整。系统渠道模式下，用户端模型选择器沿用同一渠道及模型顺序。模型排序独立保存，不改变价格、能力版本或启用状态。

系统渠道可设置可选的前台别名；为空时显示渠道名，设置后公开目录和用户会话只返回别名，后台仍保留原名。别名最长 80 字，支持后台搜索。前台模型目录模式保留其独立配置。

注册默认每 IP 每小时允许 30 次注册请求、60 次验证码请求，单邮箱每小时另限 10 次且发送后间隔 60 秒。失败尝试也占请求额度，达到上限后的拒绝不会继续增加计数或延长窗口；限流响应携带真实剩余等待时间，注册页面显示倒计时并防止重复提交。已保存的运行策略仍需管理员按实际共用网络规模调整，不随默认值升级自动覆盖。

定时闲置资源清理与后台手动删除共同保护外观配置引用的浅色 Logo、深色 Logo、登录视频及封面；即使资源超过闲置期限也不会删除，外观配置无法读取时停止相关清理。

## 章节资产提取与任务浏览

画布视频支持鼠标悬停 350ms 后静音预览前 3 秒，不循环；全局仅一个悬停解码器，离开或操作画布立即停止并恢复封面。手动播放优先，系统开启减弱动态效果时不自动预览。

剧情章节支持一次提取角色、场景与道具，分别写入角色、环境和道具待确认资产。输出必须包含三类数组；无人章节可以只产生场景或道具，不把缺失字段当作提取成功。

## AI 提示词优化器

提示词优化器是一个内置 AI 能力插件，用于把模糊的生图或生视频想法整理成可以直接使用的提示词。它复用宿主已经配置的文本模型和渠道，不在浏览器中保存或拼接第三方密钥。

### 使用入口

- 创作页 `/create` 的提示词输入框中，点击“优化”。
- 画布中的图片或视频节点提示词编辑器中，点击“优化”。

面板使用紧凑的聊天式交互，跟随当前输入框定位，支持拖动、边缘调整尺寸和窗口尺寸变化。打开与关闭不使用延迟动效，避免遮挡画布或让用户误以为请求卡住。

### 优化方式

| 方式 | 用途 |
| --- | --- |
| 扩展想法 | 从模糊想法补齐主体、场景、构图、光线、镜头等可执行细节。 |
| 精修已有提示词 | 尽量保留原意，只修正表达并补充必要细节。 |
| 强化风格 | 保留主体和动作，强化色彩、材质、光影与指定风格。 |
| 适配模型 | 按当前生成模型和协议调整提示词结构，避免使用未确认的参数语法。 |
| 结合参考 | 使用已连接的图片或文本补充外观、一致性、构图和关联关系。 |

面板底部可以单独选择优化所使用的文本模型；目标生成模型仍取当前图片或视频生成配置。两者职责不同：前者负责整理提示词，后者负责最终生成内容。

### 结果与安全边界

- 优化结果以结构化内容返回，包含正向提示词、规避项、修改说明、假设和可选备选版本。
- 结果可以继续编辑；只有点击“采用”才会回填当前输入框，并自动关闭面板。
- 请求支持流式反馈、取消和错误提示，不会在优化失败时覆盖原提示词。
- 参考素材只提交当前已连接且符合类型的内容；插件不自行访问素材库或后端密钥。

### 相关实现

- `web/src/lib/plugins/builtin/prompt-optimizer.ts`：插件清单、优化方式和模型适配策略。
- `web/src/components/canvas/canvas-prompt-optimizer-drawer.tsx`：聊天面板、拖动缩放和结果采用交互。
- `web/src/services/plugin-host.ts`：将插件文本请求接入宿主现有模型渠道。
- `web/src/pages/create/index.tsx`、`web/src/components/canvas/canvas-node-prompt-panel.tsx`：两个入口的接入。

## 画布外观

底部工具栏的“画布外观”面板支持浅色、深色、自定义三种主题，以及点阵、线稿、空白三种网格。浅色画布使用比白色节点更沉的中性雾灰背景，深色画布使用比原深色节点更亮的中性灰背景，让画布底层与内容表面保持稳定区分，同时避免蓝灰背景与黑色工具浮层产生色温割裂。

自定义主题会继承用户进入前的浅色或深色基础界面，并允许在“浅色界面”和“深色界面”之间切换。界面样式复用原项目整套节点、工具浮层、文字、边框和交互状态，不开放这些元素的任意改色；切换界面样式不会覆盖已经选择的画布背景和网格颜色。

自定义主题还允许调整画布背景色、背景明亮度、网格颜色和网格强度。颜色输入支持三位或六位 HEX，可带或不带 `#`；形成合法色码后实时写入当前画布，编辑过程中不会被父级状态覆盖，关闭外观面板也不会撤销。选择新的画布背景色时明亮度自动归零，确保画布首先精确显示输入色；之后仍可沿 OKLCH 亮度轴单独调整。不提供背景透明度，避免画布底色与底层颜色混合后产生偏色。“网格强度”使用 `0%` 最淡、`100%` 最明显的方向，避免“透明度”命名歧义。

自定义外观可以应用到当前画布，也可以保存为当前浏览器、当前账号 scope 下的新建画布默认值。当前画布外观沿用画布项目的既有持久化和同步流程；浏览器默认值不跨设备同步。

积分中心在线充值通过 `yingce.payment/v1` 支付插件接入。宿主只保存订单、加密配置、回调入账和对账；渠道协议由插件包提供。当前官方包包括微信支付 Native、支付宝电脑网站支付和虎皮椒聚合支付，包内同时带有 macOS、Linux、Windows 的 amd64/arm64 可执行文件，宿主启动时按本机系统选择。管理员在插件中心开放插件后，到支付设置填写渠道密钥即可出现在用户积分中心弹窗。扫码区固定白底深色码点；虎皮椒 `url_qrcode` 是现成二维码图片，钱包直接展示，不再二次编码。用户顶栏积分、账户卡片、命令面板、画布余额和 `/wallet` 回跳都打开同一弹窗，不再进入独立钱包页。

- `docs/content/docs/plugins/payment-plugin-runtime.mdx`：支付插件运行时协议。

## 剪辑成片（时间线编辑器）

“剪辑成片”是项目详情里的时间线编辑器入口（`/projects/:id/editor`），用于把已就绪的分镜视频编排成一段可播放、可导出的成片。它运行在浏览器本地时间线模型之上，通过后端任务队列完成语音转写与成片导出，编辑器本身不直接触碰原始媒体大文件。

### 使用入口

- 项目详情“制作流程 → 剪辑成片”步骤卡，或地址栏直接访问 `/projects/:id/editor`。
- 编辑器按项目隔离时间线状态；离开后再次进入会恢复该项目的编辑器快照。

### 当前能力

- **轨道与命令**：时间线支持添加、删除、拆分、移动、修剪片段等操作，全部通过统一命令状态机执行并进入 200 层历史记录，可撤销与重做；非法操作整批拒绝，不产生半应用状态。
- **预设面板**：左侧“添加”分类提供 8 个内置片段/字幕插件，按分类分组接入同一插槽注册链，第三方插件可与内置面板共存。
- **权限与执行边界**：命令执行遵循失败关闭（fail-closed）策略，`timeline.command` 权限与全局 `plugins.run` 权限分开控制；未授权插件或命令不会被执行或回显。
- **语音转写（字幕）**：对时间线音视频发起转写任务，转写进度沿任务 SSE 回流，完成后生成字幕轨。
- **成片导出（渲染）**：发起渲染任务，由服务端 ffmpeg 按渲染计划输出成片；渲染成功后在项目概览的“剪辑成片”步骤卡呈现“已输出 N 个成片”，并作为该步骤完成度的判定依据。
- **AI 编辑助手**：可以用自然语言描述剪辑意图，系统将其解析为受支持的命令序列；不超过 3 条命令时直接执行，多于 3 条先给出差异预览，确认后才批量执行。

### 运行环境要求

- 语音转写依赖本地 whisper.cpp 服务（`CANVAS_WHISPER_BASE_URL`），未配置时转写任务明确失败。
- 成片导出依赖服务端 ffmpeg（`CANVAS_FFMPEG_PATH`，留空时在 PATH 中查找）。
- AI 编辑助手需要可用的文本模型渠道。

### 相关实现

- `web/src/pages/projects/detail/overview.tsx`：制作流程步骤卡与成片完成度展示。
- `web/src/lib/timeline/`：时间线命令状态机、历史记录、命令 schema 与摘要（`editor-commands.ts`、`editor-history.ts`、`ai-command-schema.ts`、`timeline-summary.ts`）。

## 画布生成工具（待本地验收）

画布支持风格、运镜、九宫格提示词工具及自定义特效工具，提供收藏和私有自定义工具。工具仅加入提示词或创建待生成子节点，选择工具不自动发起生成。画布左侧提供主页、折叠、节点、资产、任务和历史菜单，不再提供独立工具菜单，展开面板沿用主分支主题。资产支持分类、搜索、分页和直接插入，复用现有素材服务及插入合同；任务和历史独立，历史明确展示最近 30 条。图片节点直接展示风格和预设，不再展示提示词模板入口；其他节点的提示词模板保持不变。
