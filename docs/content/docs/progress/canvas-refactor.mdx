## 已落地的内容

### 基线工具

- `test/fixtures/canvas-performance-project.ts` 生成固定 100、500、2000 节点及约 1.5 倍连线，图片/视频/文本/分镜表格/分组比例为 50/15/20/10/5。普通视图与概览使用同一份节点几何。
- 配套素材引用也是固定测试数据，不包含真实任务绑定；表格行默认禁用生成。媒体为本地生成的 8 张 PNG 和 1 段 WebM，不下载用户素材。后续发现 media-v1 的录屏 WebM 只有文件头、不能解码；旧性能对照仅证明图片/视频静态封面的浏览性能，不证明视频播放。media-v2 改用本地 FFmpeg 合成视频，运行前验证原生解码与播放，并记录媒体版本及哈希，禁止与旧媒体版本混合对比。
- 测试服务只监听 loopback，提供内存 API，不转发真实后端。未知接口和生成写入返回错误。生产应用仍走正常认证与画布路由，没有新增认证绕过入口。
- 在真实画布 URL 加 `canvasDiagnostics=1` 才启用诊断；移除参数或离开画布后释放观察器和 rAF。浏览器控制台可使用 `window.__canvasDiagnostics.snapshot()` / `reset()`，默认不开启、不上传。
- 采集帧间隔、长任务、输入到绘制机会的代理耗时、节点/LOD/媒体数量、已完成资源请求数、空间索引与可见性计算耗时。只输出数值统计，不收集提示词、URL 或凭据。
- 输入代理采用双 rAF，**不能等同于业务操作提交完成时间**。后续仍需补齐端到端反馈验证。
- 协议 6 逐项审计 12 次可信滚轮的数量、方向、坐标、修饰键、命中目标与前台状态，并检查最终相机恢复。分组标题属于合法平移区域，普通节点编辑器和浮层不是；多余输入不能静默过滤。正式比较要求同版脚本/夹具/媒体及输入校验器哈希、有头硬件渲染、前台空白页 120 帧采样；拒绝 CPU/trace、强制 GC、诊断 CSS、软件渲染和缺失指标，重复编号不能凑足三轮。只看设备列表中的物理 GPU 不足以通过，还核对实际 renderer 与合成/光栅状态。

### 工具栏布局读取

- CPU 采样将同步 `getBoundingClientRect` 定位到 `FloatingDock` 的 `useTransform` 回调：鼠标在工具栏外或禁用放大时，仍先读取尺寸才判断是否需要。真实组件浏览器测试先复现 5 次重渲染产生 20 次无用读取，报告 `dock-before-tests`。
- 现在先判断放大是否启用、指针位置是否有限，再读取尺寸；保留现有 Motion spring、图标、工具提示和命令处理。桌面、文字标签、窄屏、触屏、减少动画五种模式新增 36 项行为断言，读取降为零，悬停放大、离开还原、禁用按钮与焦点提示通过。连同既有 87 项检查共 123 项，无页面异常，报告 `dock-after-tests`。
- `dock-layout-cpu` 的新采样中未出现该工具栏尺寸读取栈；旧采样 `perf-v6-current-500-cpu` 曾采到约 145ms。两次是单轮无头诊断，空白页节奏不同，不能把采样时间或其帧率当成正式改善幅度。首次 `perf-v6-current-500-profile` 误把分组标题当成编辑器，保留为失败诊断，不用于验收。
- 有效的性能前后比较另用同版协议 6、media-v2、有头 Chrome、1440×1000、各三次冷/暖缓存完成，详见下一节。没有用更少的屏内节点或停用视觉效果换取指标。

- `pointercancel`、窗口失焦和 Escape 不再调用节点位置、分组或关联素材文件夹的写入路径。未移动即取消也不打开编辑面板。
- 正常松开基于最新节点合并几何；结束时重新核对当前分组几何，删除的节点不复活，也不调用其结束回调。

- 中文组合输入、编辑区域和 AntD/语义浮层中的按键、粘贴不触发画布删除/搜索/缩放等命令。行内编辑仍保留 Ctrl+S。

### 图片加载修复

- 同账号、同 URL 的在途图片加载/解码共享四槽并发队列；每个消费者有独立取消与超时，最后一个消费者离开才中止共享任务。
- 排队请求保留自身超时配置，完成/失败/取消后清除计时器、监听器和在途记录；失败允许重新请求。
- 本地候选图失败、回退图解码成功时使用真正成功的 URL；资源切换/卸载后旧恢复回调不再写状态或调用错误回调。
- 远程资源身份改变后重新判断进入视口的资格，不复用上一个资源的交叉观察状态。
- 本地 Object URL 的后续修复与十轮检查见下一节；完整远端缓存、监听器和进程内存尚未验收。

### 本地媒体缓存与刷新恢复

- `LocalMediaUrlCache` 统一图片/媒体文件的会话内 URL 所有权：同键并发读取共享一次 IndexedDB 读取和一个 URL；失败与缺失不永久缓存，各调用方保留自己的回退值。同键替换暂时保留旧版本，避免打断仍在使用它的消费者；物理删除成功后释放该键的全部版本，删除失败则保留可用资源。
- 同键写入与删除按顺序执行，避免旧删除撤销后来写入的新 URL。账号切换会清理本地 URL 并使旧读取/上传/排队写入失效；已开始的 IndexedDB 事务无法取消，但不会把结果重新发布进新会话缓存。异步上传失败后先检查会话，不再在切换账号后继续降级写入。
- 图片上传的预览所有权由 `finally` 统一清理，覆盖永久性上传拒绝、存储失败和元信息异常；瞬时上传失败且本地落盘成功时保留预览，并继续明确标记等待远端上传。HTTP 图片读取检查状态码，不把 404 正文当作有效图片继续上传。
- `cleanupUnusedMedia` 复用物理删除及 URL 清理入口。资源引用检查仍由原有上层 artifact → canvas → asset 锁序负责，缓存层不绕过引用保护，也不声称提供跨标签资源事务。
- 实际生产页面复现本地图片恢复失败：节点带有有效 IndexedDB `storageKey`，但渲染只使用已过期 Blob URL，显示空占位。图片显示现在在视口门控后按持久键解析，不把旧文档 Blob URL 当成可恢复地址；缺失文件继续显示占位，不伪造成功。通用图片组件同时识别 `generation-image:` 本地键。
- 28 项隔离 worker 行为测试覆盖并发读取、读取中删除/清空/替换、会话切换、失败重试、同键删除后写入、上传失败和十轮创建/替换/清理。初始 10 项用例有 9 项失败；追加竞争用例在初步修复上另复现 4 项失败，最终全部通过。证据为 `local-media-before.log`、`local-media-races-before.log`、`local-media-targeted-final.log`。
- 实际页面使用原生 IndexedDB、真实 PNG/WebM 和实际画布节点，两个图片节点恢复同一 URL；十轮播放、切换、离屏、返回后始终只创建 2 个共享 URL，离屏播放器每轮归零。实际 SPA 退出登录且不重载文档时全部撤销。报告为 `local-media-page-release/report.json`；图片修复前证据为 `local-media-page-before-image-fix/report.json`。
- **边界：** 这是共享本地测试资源的生命周期证据，不是独立资源大量浏览、远端 Blob 缓存、堆/监听器或进程内存验收。旧版本 URL 仍保留到该键删除或会话清空，尚未实现消费者级引用计数；不使用不安全的 LRU 撤销活动媒体。

### 视口样式更新

- 正式平移坐标直接写入世界层 `transform`，不再更新根容器的可继承 `--canvas-live-x/y`，避免平移提交把样式重算传播到全图节点。
- 节点交互降效选择器限定到画布容器，保留 Portal 工具栏的根级交互状态；导演台层级使用已有打开状态的显式标记，不通过扫描世界层后代的 `:has(...)` 判定。
- 不改变 Leafer 图形层、节点可见性规则、缩放上下限和存储格式。真实浏览器测试覆盖初始坐标、5%/50%/200% 的预览与正式状态衔接。
- 隔离实验测试过世界层布局约束、SVG 命中描边和停用动画，不能充分解决卡顿，未把这些实验规则合入产品。诊断实验不能计为功能或性能验收。

### 内容写入入口

- 节点内容更新和 120ms 媒体测量队列改用已有 `createCanvasStateWriter`，仍复用 `updateCanvasNode(s)` 做局部时间戳归并，React 只接收快照。
- 连续内容写入、鼠标命令和延迟测量以同一 `nodesRef` 为最新状态；按原顺序合并同节点测量，不覆盖并发的新内容，不复活已删除节点。
- 队列归当前画布生命周期所有，切换画布或卸载取消计时器并清空待处理测量；旧画布的迟到回调无权修改新画布，即使节点 ID 相同。
- StrictMode、一次批量发布、切换画布、卸载和迟到回调均有浏览器行为测试。此项不代表无关节点 React 订阅、保存失败重试或多标签同步已经完成。

### 保存完整性与异常恢复

- 在 4013 的真实生产页面复现：两个共享 IndexedDB 的标签修改同一标题，阻断云端 PUT 后，第二标签仍显示新标题，但 durable 记录保留第一标签内容且没有第二份草稿；刷新后第二次编辑丢失。证据为 `.local/canvas-benchmark/save-baseline/report.json`，不是推测或单纯源码判断。
- 普通保存队列现在处理 rebase 冲突：先写入现有草稿记录/索引，再提交主记录；失败不消费队列、不显示成功，提供下载副本与重试入口。写入期间的新编辑继续排队；下一次差量以本标签上次提交的快照为基线，避免把其他标签新增字段当成用户删除。
- 不同字段可以合并进本地主记录，但编辑器不是实时协作客户端。若合并结果含有本标签未看到的内容，则保留该标签草稿并暂停整份云端自动覆盖，交由用户通过现有版本/草稿入口处理。**这不是跨标签实时协作，也不承诺自动合并编辑器。** 刷新后可能展示主记录，另一分支从草稿中恢复，不把它静默丢弃。
- 用户明确选择“加载云端版”或恢复历史时，单次授权替换本地记录，并在替换前保存其他标签的 durable 分支。一般自动保存、视口变化或生成结果没有此授权；后续编辑仍走普通冲突检查。对外数据格式、节点和 Agent 协议保持不变。
- 草稿底层存储与加锁入口拆分，避免持有画布锁时递归请求同一锁。媒体清理按 artifact → canvas → asset 顺序，持有画布锁覆盖草稿引用读取至物理清理；测试验证清理期间刚形成的草稿图片不会被误删。
- 本地写入失败会明确提示不要关闭页面；草稿未确认时不再显示“已保存草稿”。旧账号保存完成不会发布到新账号的同步状态。云端保存前先完成本地队列检查，不用旧整图快照掩盖本地冲突。

### 节点渲染与几何依赖隔离

- 对资源标签、提及数组、分组子节点和批次预览做浅层派生值复用，真正变化的字段与顺序仍产生新值；不以忽略回调的 memo 比较器隐藏更新。
- 扩展节点的直接上游改为按节点提供 Context；未连接的 Markdown 等节点不再订阅整图变化。版本预览保留原有读取函数合同，连接顺序、重复来源、删除与重连语义不变。
- 普通节点不再接收业务面板回调。分镜表格只依赖行引用/输出与入边，Script 依赖行素材、图片、视频与相连成片，导演节点依赖当前场景及预览来源，Config 接收自己的输入数量和运行状态。缓存只服务渲染，生成/编辑命令继续读取最新完整图，不创建第二套业务状态。
- 连线空间索引改为几何快照和端点 ID；纯内容更新复用索引，显示连接解析最新节点对象。位置、尺寸、父分组、折叠、批次显隐与连线变化仍使索引失效。实测改名没有重建节点或连线空间索引。
- 默认关闭的诊断增加 `watchNodeRenders(ids)`；快照只输出总计数和按传入顺序排列的数字槽位，不输出节点 ID、正文或 URL。计数代表 **render attempts，不是 commits，也不覆盖所有内部组件**；重置和卸载均已测试。
- 实际生产页面专用 9 节点样例（通过隔离 `benchmark-100-spread` 路由暂时装载，测试后还原）连续两次改名，结果一致：CanvasNode **17 → 3** 次、内容 **16 → 2** 次、Frame **1 → 0** 次、上游消费者 **4 → 1** 次。剩余渲染来自编辑节点及其连接的 Markdown；独立文本、Markdown、Config、BatchTable、Script、分组及分组内文本均为零。两次都经正常保存接口持久化。
- 该样例证明更新隔离，不代表 500/2000 节点帧率达标。原始报告和截图为 `.local/canvas-benchmark/render-baseline/` 与 `render-current/`。新增行为测试覆盖相关输入回填、输出节点插入、上游删除、重连、回调替换、离屏后重新进入以及复用几何时端点内容保持最新。

### 编辑态与媒体生命周期

- 实际输入焦点加入现有可见性/LOD 规则，未选中的编辑节点也保持挂载与 full 级别；不新增业务状态仓库，不改变可见节点预算。焦点离开后释放固定，窗口临时失焦不丢弃草稿。
- 节点名称、分组名称与普通文本编辑不把中文组合输入的 Enter/Escape 当成提交或退出。真实输入法候选窗仍需用户手工验收。
- 视频激活归当前画布所有，节点删除、离开实际可见范围或切换画布时清理，即使节点仍在预加载缓冲区中也不继续播放；重新进入不自动播放。同 ID 在新画布中不会继承旧激活状态。
- 播放地址与资源身份绑定，替换资源后立即卸载旧播放源，不在异步解析新地址期间播放旧内容；普通预加载清理不会主动撤销播放 URL。
- 十轮浏览/播放的组件测试核查真实 video 的暂停、断开挂载、移除 source、`HAVE_NOTHING` 和 `NETWORK_EMPTY`。Chrome 可能保留已释放元素的历史 `currentSrc` 字符串，不能单凭字符串判定解码器仍占用资源。此项不等于完整堆、监听器和 Object URL 已全部回收。
- 测试复现 Vidstack 1.15.6 卸载后的滑块预览 rAF 回调访问已销毁状态。新增 Bun 小范围补丁，在访问滑块前检查挂载状态；dev/prod/server 三个导出一致处理，Docker 安装前拷贝补丁。未升级依赖版本或改变播放器布局，锁文件仅新增补丁声明。

最终固定协议 5 等待屏内预期图片与视频封面真实解码，逐次在真实节点间隙选择输入点，验证 12 次可信滚轮事件的累计目标相机坐标，并记录到下一次绘制机会的反馈耗时。高频事件合并到同一帧时按各事件时间戳计时，不错误要求每个中间状态单独绘制。协议 4 的探针未正确处理合帧和悬停后出现的内部滚动区域，已停止，不用于对比。

图像就绪耗时、首节点挂载耗时、预热后交互分别报告；全场景仍受 90 秒时限约束。坐标检查遍历所有挂载节点，允许的最大误差为 0.75 CSS px。反馈指标目前覆盖平移，不替代编辑、拖动、保存等业务反馈验收。

`--trace` 输出 Chromium 主线程/布局/样式轨迹；带轨迹的结果不能混入无轨迹性能对比。`--diagnostic-css=<文件>` 仅供隔离归因，CSS 内容写入报告，禁止将这类结果用于验收。**不能混合协议、夹具、有头/无头或实验设置做性能对比。**
