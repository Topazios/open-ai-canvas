# 总纲与资产总表分阶段生成

新建制作方案使用 `plan.flowVersion=1`，工作输入标识 `executionPolicy=business-batches-v3`，总纲任务另带不可变的 `planningTemplate=story-planning-v2`。不迁移历史作业，不通过修复操作自动重新收费生成历史文稿。分镜、正文、资产档案和制作规范继续由各自阶段负责。

## 制作边界

总纲确定故事讲什么、为什么发生、如何结束及每集必须交代什么，不在前置方案阶段写完整小说或逐场脚本。

| 顺序 | 固定成果 | 必须交代 | 不在本阶段展开 |
| --- | --- | --- | --- |
| 1 | 主线、结局与世界规则 | 类型承诺、目标动机、对抗、结局、时代环境、能力边界和代价 | 每场对白与镜头 |
| 2 | 人物与跨单元线索 | 主要人物身份目标、关系变化原因及线索埋设回收 | 再写一遍主线结局、逐集经历 |
| 3 | 单元阶段分配 | 集数范围、阶段目的与简短进出约束；文稿显示阶段索引 | 独立的章节全文和逐集小说 |
| 4 | 主要与单元资产登记 | 主要资产按四类并行，再按单元补齐配角、必要群体、空间、操作物件与功能声音 | 提示词、材质、机位与光照 |
| 5 | 每集叙事要点 | 剧情推进、结果变化、伏笔衔接三栏及资产引用 | 完整分集大纲、正文、对白和分镜节奏 |
| 6 | 审读与本地发布 | 单元交接、结局、远集伏笔、身份冲突、集数覆盖、实际制作需求登记和引用 | 重抄全剧与反向资产提取 |

人物、场景、道具、独立声音四类主要登记并行；随后每个故事单元只增加一次四类合并补充，不按每集每类原子化调用。单元已登记后即可编排本单元，其他单元仍可并行登记。无姓名但实际行动的配角和群体不能因不是主角而省略；路人背景不硬造个体。效果并入相关主体，触发音按声音需求登记，不另设第五类身份。不以总集数、类别比例或固定数量配额凑资产。

每集叙事要点由同一三字段定义驱动工具合同、验证和显示，每批最多八集，不跨单元。输入只保留当前参数、全局设定、所在与相邻单元、主要及本单元资产，不反复传入全剧所有配角表。三栏分别写事件、变化、线索，不重复前情和同一事件；建议合计约100至180字，但按实际复杂度调整，不设硬性长度拒收。具体分集大纲与完整正文在后续生成。可补必要新资产；普通换装、情绪及跨集出现不算新身份。

## 总纲与总表不重复生成

总纲 schema 4 固定八部分：制作范围、主线与结局、背景与规则边界、人物与关系、跨单元线索、单元阶段索引、每集叙事要点、计划资产概览。不再另设动机、冲突、完整情节、人物弧光和结局等重复叙述章节。资产部分按四类逐项完整显示名称、简介与别名、剧情用途、必要变体及计划范围，不再压成分类数量和名称串；后续材质、摄影及生成提示词不在这里展开。

故事发布后，`flowStoryUnits` 指向已采用的结构化记录。资产总表按这些记录本地生成：

1. 采用主要与单元登记，加入叙事要点提出的必要新身份。
2. 合并同类别同规范名称的稳定身份，汇总各集使用关系。
3. 按类别及登记主次生成连续显示序号，由现有服务端分配器登记正式资产编码。
4. 通过现有清单完整性、引用和依赖检查，整体发布。

这条路径只有本地 `catalog` 检查点及发布，不再调用提取、补漏、身份归并 Agent，也不重新审读完整总纲。重试复用已登记 key 和正式编码。相同类别、规范名称采用稳定 key；与主要登记精确匹配的无歧义别名复用原身份。跨单元同名登记合并用途、范围与别名，模糊或冲突身份仍需语义审读，不承诺自动识别一切身份重复。

总纲与总表共用 `productionPlanningAssetTables`，每条登记都显示，不截取前几项或再让模型摘要。总纲六列为序号、名称、简介与别名、剧情用途、必要变体、计划范围；总表在相同记录上增加正式编码与精确使用集数。类别内序号从一开始，统计为基础身份数，不等于变体、图片或声音文件数量。声音按实际可独立复用的声源与功能登记，不和人物数量配比；人物对白声线仍归人物档案。

具名或承担独立行动的匿名人物不能被宽泛群体条目吸收；不需辨认个体的集体活动仍可使用群体身份。各场景、线索与操作物件按独立空间或实物登记，不能将多项独立需求并为泛称“材料”。必要变体写明确年龄阶段、重大形态、身份造型或结构变化；情绪、普通动作、日夜与一般污损属于连续性，不用它们充当设计变体。该粒度通过生成字段说明与语义审读约束，不用脆弱关键词或资产数量门槛拒收正常故事。

资产登记是前置计划，不表示最终剧本已穷举全部道具和声音。后续分集大纲、正文新增的制作需求须明确补录。身份约束、别名及变体随资产索引交给详细设计阶段，具体光照、构图、道具交互和镜头参数在对应阶段展开。

## 导入文本的提取路径

导入已有小说、剧本而没有本轮规划记录时，仍需从文本提取资产，不使用空登记替代。相邻来源按业务批次提取，同次完成候选、四类覆盖、声音及逐份来源核对。

候选必须有真实来源和精确原文，来源归属由已验证的 `candidate.sourceRef` 推导，模型不再维护重复的候选引用表。缺少来源、非法引文或真实身份冲突仍阻止采用，不能用宽松匹配掩盖错误。

该路径保留类别并行、类别内顺序归并及有证据的身份复核。显式重新核对可增加补漏；完整结果整体替换旧登记，已有资产制作后不就地改写引用。显示序号按类别从一开始，正式编码允许历史预留间隔。

## 校验与修复

本地先核对 JSON、字段、集号、身份类别和引用；语义审读只针对该阶段应交付的内容。任务卡不因缺少完整对白、摄影或造型细节而被判不合格。

每单元按最多十六集一组检查本组及相邻交接，审读输入同时包含主要与相关单元资产，检查事件已写出的行动者、空间、关键操作物件和功能声音是否漏登漏引。缺漏必须引用具体集的实际事件，以 `rule_violation` 定向要求补 `newAssets` 或 `assetKeys`；不能为未写出的陈设或造型细节报错。全剧另用伏笔、结果变化和新增身份的紧凑投影核对结局及远集回收。完整记录指纹参与审读身份，修改后不能复用旧审批。

结构修复保留已经合格的兄弟集，只补未完成集；明确的语义矛盾允许修改被指向的已采用集。截断仅恢复完整闭合且独立验证通过的数组成员，不补引号、不编造尾部剧情。

每单元保留初次调用、最多两次内容修复及一次有依据的范围拆分。拆分子结果经父记录本地聚合后重新验证，不重复统计，不再收费汇总。明确临时故障沿用有界重试、退避和共享连续无进展保护；鉴权、余额、审核及取消待核对问题不盲目重发。已通过工作不重跑。

## 调度、保存与恢复

任务表、检查点和执行代次仍是权威状态。一次批量接纳或结算有限数量工作，实际并发服从 Agent、用户和渠道配置；并发不是为每个字段创建一个驻留 Agent。

主任务租约、检查点恢复、取消与迟到写入隔离保留。结果和通知事件在同一事务保存；页面断线从服务端快照重建，不因通知丢失重新生成。服务排空释放租约，恢复读取原分配，不能把所有子任务重新派发。

合格接收恢复连续无进展额度，累计次数保留。持续没有进展时自动降低并发并按十五、三十、六十秒有界恢复；耗尽后保留原因和手动继续入口。人工暂停不会偷偷恢复，未知收费状态不自动重发。

本地发布失败保留已采用内容，重试只重放本地存储与发布。来源版本、用户归属、目标删除及人工修改保护继续检查。规划资产总表的显示修改不会引发一次付费反向提取。

## 共用规范生成

视觉、导演和生成一致性规范在总表完成或明确暂缓后可并行执行，不再让生成一致性规范等待另两份规范。每次仅携带总纲的完整主线、规则、人物关系等公共依据，排除逐集巨表和资产明细，保留项目画幅、风格、时长等参数。此裁剪仅用于共用规范，不影响资产档案和逐集内容的来源。

规范按最多五个章节一批保存私有检查点；超时后缩小当前未完成批次，已接受章节不重写，所有章节合并校验后才发布。人工编辑过的规范不被覆盖，重建结果另存为候选并保留旧文本，避免反复调用模型修复版本冲突。删除的目标仍受保护。

画布文稿卡片和预览窗显示完整源文本的字符数，不用裁切预览计算；窄屏保留字符数。只预览、切换源码或改标题不重新序列化正文，避免换行格式变化被误判为正文修订。

## 文稿显示

新总纲按主线规则、人物关系、单元分配、主要与单元资产、每集要点、审读、发布显示。资产阶段在单元确定后使用“四类主要登记加单元数”的分母；集数进度仍按项目配置，不按请求数或拆分子任务计数。未发布内容不冒充最终完成。

结构化总表只显示本地资产汇总和发布，不等待不存在的提取步骤。导入文本总表继续显示实际提取、归并与复核进度。暂停、自动等待与运行状态分开，并保留具体原因及恢复入口。

现有大文稿 Worker 解析、表格行虚拟化和 CodeMirror 编辑保留，不因总纲减负而退回主线程全量渲染。任务详情延迟挂载并分批展开工作记录。

## 验收范围

离线测试覆盖真实保存和发布事务、长篇任务卡、局部补写、截断完整成员、拆分汇总、稳定资产复用、来源归属、重复回执和旧代次隔离。

离线回放证明合同与恢复机制，不证明真实渠道一次完成、实际耗时或文学质量。本次不主动触发付费模型调用，也不迁移现有业务数据。实际内容质量及跨阶段新增需求仍需真实项目验收。
