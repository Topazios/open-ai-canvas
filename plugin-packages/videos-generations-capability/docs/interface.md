# Videos Generations Capability 接口字段

## 协议身份

- 插件 ID：`videos-generations-capability`。
- Provider ID：`videos-generations-capability`。
- 能力：`video`。
- 默认 Base URL：`http://127.0.0.1:3000`。
- 鉴权驱动：`bearer`。
- 创建：`POST /v1/videos/generations`。
- 查询：`GET /v1/videos/generations/{{taskId}}`。

## 配置字段

| 字段 | 类型 | 必填 | 含义 |
| --- | --- | --- | --- |
| `apiKey` | secret | 是 | API Key |

## 统一字段映射

| 统一字段 | 类型 | 必填 | 上游映射 | 说明 |
| --- | --- | --- | --- | --- |
| `model` | string | 是 | `model` | 视频模型 ID。 |
| `prompt` | string | 是 | `prompt/content/input` | 视频提示词。 |
| `images` | media[] | 否 | `first/last/reference image` | 显式 role 图片输入。 |
| `videos` | media[] | 否 | `reference video` | 参考视频。 |
| `audios` | media[] | 否 | `reference audio/voice` | 参考音频或音色。 |
| `duration` | integer | 否 | `duration/seconds` | 时长秒数。 |
| `aspectRatio` | string | 否 | `ratio/aspect_ratio/size` | 画幅比例或尺寸。 |
| `resolution` | string | 否 | `resolution` | 分辨率档位。 |
| `generateAudio` | boolean | 否 | `generate_audio` | 是否生成音频。 |
| `watermark` | boolean | 否 | `watermark` | 水印开关。 |
| `providerOptions` | object | 否 | `provider-specific fields` | 插件命名空间内的厂商扩展字段。 |

## 响应与错误

插件把上游 task/status/text/media/usage 映射为统一结果。临时媒体 URL 标记为 ephemeral，由宿主立即下载持久化。HTTP 错误、业务 code 和 error object 保持失败语义，不包装成成功。

## 兼容边界

该协议对应以复数路径 /v1/videos/generations 创建、/v1/videos/generations/{id} 查询、/v1/videos/{id}/content 下载的网关。请求体只携带模型能力声明过的字段：model、prompt、整数 duration、resolution、reference_image_urls 与 first_image_url/last_image_url。不发送 seconds、generate_audio、aspect_ratio。参考图与首尾帧互斥，首尾帧必须成对，参考图最多 5 张。下载接口返回 409 表示结果未就绪，由宿主继续轮询。单数路径 /v1/video/generations 属于 NewAPI Video Generations Channel 2，不能与本协议混用。
